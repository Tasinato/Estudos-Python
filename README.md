# Estudos-Python

Este repositório tem o objetivo de compartilhar código comentado de programas escritos durante meus estudos de Python.

## Registro de aprendizado

Os arquivos preservam exercícios e anotações de cursos, incluindo versões produzidas durante o aprendizado. Eles podem conter tentativas, comentários e pontos a melhorar.

### Curso de Luiz Otávio — Udemy

Na pasta [Cursos/LuizOtavio-Udemy-Python3.0](Cursos/LuizOtavio-Udemy-Python3.0), estão exercícios de:

- Iteração de strings com `while`.
- Laços de repetição e calculadora.
- Contadores, acumuladores e `while/else`.
- Cálculo de dígitos verificadores de CPF.

Os comentários dos arquivos registram o professor, a plataforma e Rafael Tasinato como aluno. Os créditos das orientações e propostas dos cursos pertencem aos respectivos professores; este repositório registra minha prática como estudante.

## Material didático relacionado

O [PythonAulas](https://github.com/Tasinato/PythonAulas) reúne atividades organizadas para estudo e ensino, com enunciados, exemplos e comparação entre programação sequencial, funções e orientação a objetos.

O PythonAulas está privado no momento; seu conteúdo é acessível apenas a pessoas autorizadas. Este Estudos-Python permanece como registro dos cursos e da trajetória de aprendizado.
